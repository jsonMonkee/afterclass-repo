# 🍌 Afterclass — Amity University Kolkata

> *"Amity placement cell ke jhoothe promises aur official WhatsApp groups ke 1000 spam notifications se thak chuke ho? Welcome to Afterclass, bsdk."*

Afterclass is the high-energy student commons built specifically for **Amity University Kolkata**. Kyunki college ka official portal dekh kar lagta hai 2004 mein kisi ke chacha ne dial-up internet par CSS bhool kar banaya tha. Aur important fest circulars? Wo toh 500 "Good Morning Beta 🙏" forwards ke neeche dafan ho jaate hain.

Built by students, managed by students, and powered with zero corporate nautanki by the bhaiyas at **[wyrcan.io](https://wyrcan.io)**.

---

## ⚡ Yeh Karta Kya Hai? (Features)

- **🎪 Fests & Auditions Feed** — Konse lawn mein open mic hai, kahan hackathon chal raha hai, aur AmiFIESTA ke passes kaise milenge. Sab verified, zero fake hype.
- **🎭 Student-Led Clubs Directory** — Cadence, Turing, E-Cell, NatyaRang se lekar Aperture tak. Kaun kab recruit kar raha hai direct apply link ke saath. Koi botla admin ka permission nahi chahiye.
- **📢 The Uncensored Campus Gazette** — Notice board with actual dates and news. "Posted by Deepak Kalal" level honesty, no college PR sugarcoating.
- **💼 Real Off-Campus Opportunities** — Real internships, hackathons, and open-source gigs. Hum placement cell ki tarah 1.5 LPA cold-calling sales roles chipka kar "100% Placement Record" ka dhol nahi peet-te.
- **🍌 Choto Bantu AI 2.0** — Tumhara Amity campus companion. Poocho fest kab hai, auditions kahan hain, ya Major Arterial Road canteen mein kya khana layak hai.
- **🏎️ Butter-Smooth Kinetic UI** — Lenis smooth scroll, GSAP reveals, and signature crimson vibes (`#E11D48`). Aankhon ko sukoon milega.

## 🛠️ Khaandaani Tech Stack

| Thing | Kya Use Kiya | Kyun Use Kiya |
|---|---|---|
| **Framework** | Next.js 16 (App Router + Turbopack) | Kyunki fast hai aur hume wait karna pasand nahi |
| **Styling** | Tailwind CSS + Custom Crimson Tokens | `#E11D48`, `#881337`, `#FFFDF5` |
| **Animations** | GSAP (`ScrollTrigger`) + Lenis | Smooth scrolling taaki portfolio classy lage |
| **Icons** | Lucide React | Clean, scalable icons |
| **Minds Behind It** | [wyrcan.io](https://wyrcan.io) Studio | Amity ke apne bhaiyas |

## 🚀 Local Setup (Aukaat Check)

Agli baar repo dekh kar mat sochna ki code run nahi hoga. Yeh 3 commands chalao:

```bash
# 1. Clone maar lo
git clone https://github.com/jsonMonkee/afterclass-repo.git
cd afterclass-repo

# 2. Dependencies install karo (node_modules ka vajan sah lena)
npm install

# 3. Dev server chalao
npm run dev
```

Browser kholo aur aukaat dekho: [`http://localhost:3000`](http://localhost:3000)
